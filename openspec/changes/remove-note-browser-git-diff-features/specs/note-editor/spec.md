## REMOVED Requirements

### Requirement: Markdown 所见即所得编辑
**Reason**: 笔记编辑器被移除，应用不再提供内置 Markdown 所见即所得编辑。
**Migration**: 使用外部 Markdown 编辑器编辑笔记文件。

### Requirement: 编辑器主题适配
**Reason**: 笔记编辑器被移除，不再需要编辑器专属主题适配。
**Migration**: 应用主题系统继续服务保留的终端、文件树和文件预览。

### Requirement: 编辑器内容变更通知
**Reason**: 笔记编辑器被移除，不再有笔记内容变更回调。
**Migration**: 无应用内迁移路径。
