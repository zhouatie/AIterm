## Why

当前文件树右键菜单虽然会在接近窗口右边缘时反向弹出，但不会考虑文件树面板自身的右边界。在左侧文件树较窄、右侧内容区较宽时，菜单会向右溢出到相邻面板，看起来像被文件树右侧“挤出去”，影响可读性和可操作性。

这个问题已经在现有实现中稳定复现，且影响文件树最基础的路径类操作，适合用一个小范围变更把菜单约束回文件树可视区域内。

## What Changes

- 调整文件树右键菜单的定位边界，从仅基于窗口视口改为优先基于文件树面板可视区域。
- 让文件树在触发右键菜单时同时传递宿主容器的可视边界信息，而不只传鼠标坐标。
- 保持现有菜单项、关闭行为、复制行为和视觉样式不变，只修正越界定位逻辑。

## Capabilities

### New Capabilities

无

### Modified Capabilities

- `file-preview`: 文件树右键菜单在接近文件树面板边缘时必须调整弹出方向，完整显示在文件树面板可视区域内。

## Impact

- 受影响代码：`src/components/FileTree.tsx`、`src/components/ContextMenu.tsx`
- 受影响行为：文件树节点右键菜单的水平定位和边界避让
- 不涉及新的依赖、IPC、数据结构迁移或外部接口变更
