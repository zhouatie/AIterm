## REMOVED Requirements

### Requirement: 笔记面板 Overlay 交互
**Reason**: 笔记面板被移除，标题栏不再提供笔记入口。
**Migration**: 使用外部 Markdown 编辑器或文件系统管理笔记。

### Requirement: 笔记面板保留开关键
**Reason**: 笔记面板和其快捷键被移除，不再需要在编辑器或搜索框焦点下保留开关键。
**Migration**: 旧的笔记快捷键绑定不再生效。

### Requirement: 笔记工作台布局
**Reason**: 笔记工作台被移除，不再提供 Vault Explorer 与编辑区布局。
**Migration**: 使用外部笔记工具维护 Vault 或 Markdown 文件。

### Requirement: 单文档编辑流
**Reason**: 应用不再提供笔记文档编辑器。
**Migration**: 使用外部 Markdown 编辑器编辑文件。

### Requirement: 合并导航树
**Reason**: 笔记 Vault 文件树被移除。
**Migration**: 可通过系统文件管理器或外部笔记工具浏览目录。

### Requirement: 笔记文件列表工具栏
**Reason**: 笔记 Vault Explorer 被移除，不再需要其顶部控制条。
**Migration**: 无应用内迁移路径。

### Requirement: 笔记文件列表
**Reason**: 笔记文件树被移除，不再扫描和展示 Vault 下的笔记列表。
**Migration**: 使用外部工具浏览笔记文件。

### Requirement: 笔记文件树右键菜单
**Reason**: 笔记文件树被移除，不再提供笔记上下文菜单。
**Migration**: 使用系统文件管理器或外部编辑器执行新建、重命名、删除等操作。

### Requirement: 文件树拖拽移动
**Reason**: 笔记文件树被移除，不再支持应用内拖拽移动笔记节点。
**Migration**: 使用系统文件管理器或外部笔记工具移动文件。

### Requirement: 笔记文件搜索
**Reason**: 笔记工作台被移除，不再提供 Vault 内搜索。
**Migration**: 使用外部笔记工具、系统搜索或终端命令查找文件。

### Requirement: 新建笔记
**Reason**: 应用不再提供笔记创建入口。
**Migration**: 使用外部编辑器或终端创建 Markdown 文件。

### Requirement: 新建文件夹
**Reason**: 笔记工作台被移除，不再提供 Vault 内新建文件夹入口。
**Migration**: 使用系统文件管理器或终端创建文件夹。

### Requirement: 重命名笔记
**Reason**: 笔记工作台被移除，不再提供笔记重命名入口。
**Migration**: 使用系统文件管理器、终端或外部笔记工具重命名文件。

### Requirement: 重命名文件夹
**Reason**: 笔记工作台被移除，不再提供文件夹重命名入口。
**Migration**: 使用系统文件管理器、终端或外部笔记工具重命名文件夹。

### Requirement: 删除笔记
**Reason**: 笔记工作台被移除，不再提供笔记删除入口。
**Migration**: 使用系统文件管理器、终端或外部笔记工具删除文件。
