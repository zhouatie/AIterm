## Why

当前终端 Tab 栏采用扁平方块 + 右边框分隔 + 底部蓝线激活指示器的设计，视觉上接近 VS Code 2018 的风格，缺乏精致感和个性。对于一个独立终端应用，Tab 栏是用户最频繁交互的 UI 之一，需要更优雅的视觉表现和更丰富的交互反馈来提升产品质感。

## What Changes

- **Tab 形态重构**：从方块 + 边框分隔改为「胶囊药丸」造型（`border-radius: 8px`），去掉 Tab 之间的分隔线
- **激活态重设计**：去掉底部蓝色下划线，改为填充背景 + 柔和阴影的药丸效果
- **Hover 态增强**：非激活 Tab hover 时淡入半透明药丸背景，文字颜色变亮
- **关闭按钮交互优化**：关闭按钮仅在激活态和 hover 态可见，按钮改为圆形（`border-radius: 50%`）
- **点击微反馈**：Tab 点击时增加 `scale(0.97)` 按压反馈
- **新建按钮升级**：从纯文字 `+` 改为 lucide `Plus` 图标，与药丸风格统一
- **Tab bar 布局调整**：高度从 36px 提升到 40px，去掉底部分隔线，Tab bar 与终端内容区自然融合
- **过渡动画增强**：所有状态变化增加 0.15~0.2s 的平滑过渡

## Capabilities

### New Capabilities

（无新增能力）

### Modified Capabilities

- `terminal-tabs`：Tab 栏视觉样式和交互行为变更——Tab 形态从方块改为药丸胶囊，激活指示器从底部边框改为填充背景+阴影，新增 hover 态、点击按压反馈、关闭按钮条件可见性等交互增强

## Impact

- **受影响代码**：`src/components/TerminalTabBar.tsx`（样式对象重写 + 渲染逻辑调整）
- **依赖变更**：使用已有的 `lucide-react` 库的 `Plus` / `X` 图标组件
- **主题系统**：复用现有 CSS 变量，可能需要新增 1-2 个变量用于药丸半透明背景色
- **无 breaking changes**：纯视觉层改动，不影响 Tab 的功能逻辑和 PTY 生命周期
