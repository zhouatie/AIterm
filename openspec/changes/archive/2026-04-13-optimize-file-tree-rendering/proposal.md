## Why

当前文件树在大根目录下会初始化展示所有 Markdown 文件及其目录结构，虽然主进程已使用 `fd` 做全量扫描，但渲染进程仍会递归挂载完整树节点，导致初始化和展开目录时明显卡顿。

这次优化将文件树初始加载改为只读取第一层目录，避免进入大根目录时立即全量扫描；普通项目目录仍支持用户手动点击“展开全部”后再执行全量展开。

## What Changes

- 文件树初次加载任意根目录时只请求第一层 tree。
- 用户展开某个目录时，只请求该目录的下一层 tree，并缓存到该目录节点下。
- 折叠目录下的子节点不挂载到 React 树中，只有目录展开后才渲染可见子节点。
- 移除 Markdown-only / 全部文件切换按钮，默认按全部文件加载。
- 文件树工具栏新增搜索框，用于过滤当前已加载的树节点。
- 文件树工具栏新增 spec 模式按钮；开启后根目录只加载配置的 spec 目录名（默认 `openspec`、`ravenspec`）对应的目录。
- spec 模式按钮显示 `spec` 文本；开启 spec 模式时只直接访问配置的 spec 目录路径，不先读取根目录所有 entry 后过滤。
- spec 模式下点击展开全部时，只扫描并展开配置的 spec 目录树，不包含非 spec 目录。
- 设置面板新增 spec 目录名配置，支持用户扩展目录名列表。
- 文件树渲染改为基于当前展开状态生成可见行列表，并使用固定行高虚拟列表，仅渲染视口内的节点。
- 高层级目录（文件系统根目录、`/Users`、当前用户 Home）隐藏“展开全部”按钮。
- 非高层目录保留“展开全部”按钮；用户点击后执行全量扫描并展开所有目录，DOM 挂载数量仍受虚拟列表限制。
- 选中、右键菜单、刷新等现有交互保持不变。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `file-preview`: 文件树 SHALL 初次只加载第一层，支持按目录逐层展开；非高层目录 SHALL 支持手动展开全部，高层目录 SHALL 隐藏展开全部入口；大量可见节点时使用虚拟化渲染保持交互性能。
- `settings-panel`: 设置面板 SHALL 支持配置 spec 模式使用的目录名列表。

## Impact

- 主要影响 `src/main.ts`、`src/preload.ts` 和 `src/components/FileTree.tsx` 的目录读取 API、树加载结构、展开状态处理和滚动容器实现。
- 可能少量影响文件树样式，需保持现有行高、缩进线、图标、选中态和右键菜单视觉行为。
- 新增直接子节点读取 IPC；保留现有全量扫描 IPC 作为非高层目录“展开全部”的实现路径；不新增第三方依赖。
- 不改变 preload API、文件读取 API、终端 CWD 同步逻辑或 Markdown/代码预览逻辑。
